# 🎮 RPS Arena - Rock Paper Scissors Game

A modern and interactive Rock Paper Scissors game built using HTML, CSS and JavaScript.

## 🌐 Live Demo

https://vanshika2723.github.io/Rock-Paper-Scissors/


## ✨ Features

- Rock, Paper and Scissors gameplay
- Computer-generated moves
- Endless Mode
- Best of 3 Mode
- Best of 5 Mode
- Real-time score tracking
- Win and loss tracking
- Current win streak
- Best streak
- Achievement system
- Match history
- LocalStorage support
- Dark and Light theme
- Sound effects
- Sound toggle
- Win celebration with confetti
- Game-over winner modal
- Keyboard controls
- Responsive design
- Smooth animations
- Reset game option

## 🕹️ How to Play

1. Open the game in your browser.
2. Select a game mode.
3. Choose Rock, Paper or Scissors.
4. The computer will automatically select its move.
5. The game will display the result.
6. Try to build the highest winning streak.

## ⌨️ Keyboard Controls

R = Rock

P = Paper

S = Scissors

ESC = Close Game Modal

## 🏅 Achievements

First Victory - Win your first game

On Fire - Reach a 3 win streak

Unstoppable - Reach a 5 win streak

Veteran - Play 10 games

Perfect Run - Win 5 games in a row

## 🧠 Game Rules

Rock beats Scissors.

Scissors beats Paper.

Paper beats Rock.

Same choice results in a Draw.
